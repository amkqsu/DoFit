# DoFit 4.0.0

Package: `com.dofit.app`

Native Android project using Kotlin, Jetpack Compose, Room, WorkManager, AlarmManager and Jetpack Glance. All application data is local.

The visual palette follows the DoWatch reference: #0D0D0E background, #19191B surface, #272729 raised, #303034 separators, #F5F5F7 text, #99999F muted, #C7C7DB accent.

This project was reconstructed from the requirements available in the current chat because the prior DoFit source project was not present in the Library.
